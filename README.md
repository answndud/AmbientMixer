# 🎧 Ambient Mixer - 앰비언트 사운드 믹서

집중력 향상과 휴식을 위한 화이트 노이즈 및 환경음 믹서입니다.

## ✨ 기능

- 🎧 **12가지 환경음**: 비, 천둥, 모닥불, 바람, 파도, 새소리, 카페, 키보드, 화이트/브라운/핑크 노이즈, 귀뚜라미
- 🎚️ **개별 볼륨 조절**: 각 사운드의 볼륨을 독립적으로 조절
- 🔊 **마스터 볼륨**: 전체 볼륨 한 번에 조절
- ⏱️ **타이머 기능**: 15분, 30분, 1시간 후 자동 정지
- 💾 **프리셋 저장**: 나만의 믹스를 저장하고 불러오기
- 🌓 **라이트/다크 모드**: 원클릭으로 테마 변경
- 📊 **시각적 피드백**: 재생 중 비주얼라이저 표시

## 🚀 사용 방법

1. **사운드 선택**: 원하는 사운드 카드의 토글 버튼을 클릭하거나 볼륨을 조절
2. **재생**: 가운데 재생 버튼 클릭
3. **믹싱**: 각 사운드의 볼륨을 원하는 대로 조절
4. **프리셋 저장**: 마음에 드는 조합을 프리셋으로 저장
5. **타이머 설정**: 자동 종료 시간 설정

## 🔊 기술적 특징

### Web Audio API 활용

모든 사운드는 브라우저에서 실시간으로 생성됩니다:

- **노이즈 생성**: AudioBuffer에 랜덤 값 채워서 생성
- **필터링**: BiquadFilter로 주파수 특성 조절
- **이펙트**: 천둥, 새소리 등은 Oscillator와 Envelope으로 구현
- **믹싱**: GainNode 체인으로 볼륨 제어

### 프로시저럴 사운드

```javascript
// 브라운 노이즈 생성 예시
let lastOut = 0;
for (let i = 0; i < bufferSize; i++) {
    const white = Math.random() * 2 - 1;
    output[i] = (lastOut + (0.02 * white)) / 1.02;
    lastOut = output[i];
}
```
